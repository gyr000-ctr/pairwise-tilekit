# pairwise-tilekit

## 题面（可直接粘贴）

网格 A* 寻路。约束：路径步数等于 BFS 最短路；不可达返回 None；起点/终点越界或为墙要报错；路径相邻且不含墙；512x512 网格单次寻路不超过 200 ms、内存不随网格规模平方增长；结果确定可复现；并发寻路同一网格安全。验收：python -m pytest tests -q -k astar。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 对角代价
- 大网格耗时
- 并发
- 起点=终点
- 墙的边界

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线）。
